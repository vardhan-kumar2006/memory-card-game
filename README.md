# 🧠 FlipMatch - Emoji Memory Card Game

A fun, fast, and addictive **Emoji Memory Matching Game** built with pure HTML5, CSS3, and modern Vanilla JavaScript. Test your photographic memory, match the pairs, and beat your best score!

---

## 🎮 Game Highlights & Features

- **🃏 3D Smooth Card Flips**: Realistic card flipping animations using CSS 3D transforms (`preserve-3d`, `rotateY`).
- **🎵 Synthesized Sound Effects**: Built-in audio chimes and victory fanfare using the native **Web Audio API** (Zero external audio file dependencies!).
- **⏱️ Live Stopwatch & Move Counter**: Dynamic timer, move tracker, and star rating system (⭐⭐⭐).
- **🏆 Best Score Persistence**: Remembers your lowest move record using `localStorage`.
- **🎯 Multiple Difficulties**: Toggle between **Easy (12 Cards - 6 Pairs)** and **Normal (16 Cards - 8 Pairs)**.
- **🎉 Confetti Victory Celebration**: Canvas-based particle explosion effect upon completing the game.
- **📱 100% Responsive & Mobile-Ready**: Optimized for phones, tablets, and desktop displays.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup, modal overlays, accessibility.
- **CSS3**: Glassmorphism, CSS Grid, 3D flip transforms, keyframe animations, glow orbs.
- **JavaScript (ES6+)**: Fisher-Yates shuffle algorithm, Web Audio API sound synthesis, Canvas confetti particle system, DOM state manipulation, and LocalStorage persistence.
